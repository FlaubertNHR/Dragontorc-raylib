# Dragontorc/Avalon raylib retro-remake

My goal is to try to recreate a framework for games similar to Dragontorc,
Avalon, or Astroclone, created in the 1980s by Steve Turner.

For this, I will use [raylib](https://www.raylib.com/) as a framework, 
programming in C within a Linux environment (though the code should 
also be executable on other operating systems supported by raylib).

Initially, I will focus on the game engine, leaving the graphics, music,
etc., for later. Any collaboration is welcome (write to flaubertSt@gmail.com).

## Installation and execution

You need to install the raylib framework in order to build and run this game. 
Installation instructions for various platforms can be found [here](https://github.com/raysan5/raylib/wiki).

Generally, the simplest approach is to follow the quick installation instructions 
and replace the example code provided during that installation with the code for 
the retro-remake.

## About Dragontorc

Dragontorc is an action-adventure game developed by Steve Turner’s Graftgold and released for the 
Amstrad CPC and ZX Spectrum by Hewson Consultants in 1985. It is a sequel to the 1984 game *Avalon:
The 3D Adventure Movie*. The hero of *Avalon*, Maroc the Mage, returns to defeat an evil witch and 
save Britain.

This is a long game with a certain level of complexity, as it is not always clear what needs to be 
done next. One aspect I would like to improve is the addition of more hints and information to guide
the player—for instance, by allowing them to "converse" with other NPCs.
